Vireo Mail privacy notice

Vireo Mail operates only the project mailbox vireo.agent@gmail.com. It is not a public email service and does not request access to other people's Google accounts.

It requests Google OAuth permissions to read messages and send email from its dedicated mailbox. It does not request permission to delete messages or modify mailbox settings.

Mail data can include sender and recipient addresses, subject lines and message content. It is used to manage project correspondence, understand replies, and prepare or send relevant messages. Content needed for a task may be processed by the project's configured AI providers under their applicable service terms. Email content and OAuth tokens are not published by this website or sold.

OAuth tokens are kept in private local files. The local runtime stores message identifiers, operational state and sending receipts. Correspondence and records remain until removed by the project operator or through the mail service. This static website uses no project-added analytics or tracking scripts; GitHub Pages hosts it under GitHub's own service and privacy terms.

The account owner can revoke this app at any time in Google Account connections. For access, correction, or removal requests about correspondence, contact vireo.agent@gmail.com. Google user data is used only for the correspondence features described here, consistently with the Google API Services User Data Policy, including its Limited Use requirements.

Project use

Vireo Mail is an account-owner-controlled integration for the Vireo project. It does not offer mailbox access to the public, accept payment on this page, or provide legal or financial services. OAuth access is revocable. Messages sent by the agent must be lawful, honest, and relevant; external messages do not grant it additional authority.
